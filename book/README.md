# Vkbots

Асинхронная библиотека для разработки ботов ВКонтакте на Rust.

Vkbots предоставляет общий клиент VK API, отправку сообщений, обработку Callback API и получение обновлений через Bots Long Poll.

Читайте руководство по порядку или переходите сразу к нужной теме.
