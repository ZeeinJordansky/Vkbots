# Клиент и конфигурация

## Создание

```rust
use vkbots::VkBot;

let bot = VkBot::new("ТОКЕН_СООБЩЕСТВА");
```

Для дополнительной настройки используйте builder:

```rust
use std::time::Duration;
use vkbots::VkBot;

let bot = VkBot::builder("ТОКЕН_СООБЩЕСТВА")
    .api_version("5.199")
    .timeout(Duration::from_secs(20))
    .build()?;
```

## Поля клиента

- `bot.api` — универсальный клиент VK API.
- `bot.send` — методы отправки сообщений.

Оба компонента можно клонировать. HTTP-клиент переиспользуется, поэтому не нужно создавать новый клиент на каждое событие.

## Debug

Отладочный вывод клиента не показывает значение токена. Не выводите токен отдельно и не включайте его в журналы приложения.
