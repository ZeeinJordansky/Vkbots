# Ограничения и безопасность

## Токены

Токен сообщества передаётся клиенту при создании. Не размещайте токены в публичном репозитории, логах, сообщениях об ошибках и примерах, предназначенных для публикации.

Реализация `Debug` для API-клиента скрывает значение токена. Это не защищает от явного вывода токена самим приложением.

## Callback API

Используйте HTTPS и задавайте секретный ключ в настройках сообщества и в `CallbackConfig`. Проверка идентификатора сообщества и секрета выполняется до вызова пользовательского обработчика.

Событие может быть доставлено повторно. Для защиты от дублирования сохраняйте обработанные `event_id` и делайте обработчики идемпотентными.

## Права доступа

Библиотека не обходит ограничения VK API. Ошибки прав доступа, лимитов запросов, блокировок и доступности методов возвращаются приложению.

## Совместимость

Версия VK API задаётся строкой через builder. Формат объектов и поведение методов следует сверять с документацией VK для используемой версии.
