# Production: Callback API за Nginx

В репозитории есть пример конфигурации Nginx: `config/nginx/vkbots.conf`. Он принимает HTTPS на публичном домене и проксирует запросы на локальный CallbackServer.

## Порядок запуска

1. Настройте DNS домена и TLS-сертификат.
2. Разместите конфигурацию Nginx, заменив `bot.example.com` на свой домен.
3. Запустите пример `callback_nginx` на `127.0.0.1:3000`.
4. Укажите в настройках сообщества Callback API URL вида `https://bot.example.com/vk/`.
5. Выберите события, которые VK должен отправлять.
6. Введите секретный ключ и строку подтверждения, совпадающие с настройками процесса.

Запуск примера:

```bash
VK_TOKEN=... VK_GROUP_ID=123456 VK_CALLBACK_SECRET=... VK_CONFIRMATION_KEY=... cargo run --example callback_nginx
```

## Что проверить перед запуском

- Порт 3000 не должен быть открыт наружу: доступ к приложению идёт через Nginx.
- Callback API должен быть настроен на HTTPS.
- Секретный ключ должен совпадать в настройках VK и приложении.
- Процесс бота должен автоматически перезапускаться службой управления процессами.
- Долгие операции в обработчиках следует выносить в очередь задач приложения.
- Для нескольких экземпляров бота FSM и ограничитель запросов должны использовать общее внешнее хранилище или координацию.
