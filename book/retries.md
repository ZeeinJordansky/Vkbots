# Ограничение запросов и повторные попытки

Каждый клон API-клиента использует общий ограничитель частоты запросов. Стандартный предел — 3 запроса в секунду на один экземпляр клиента. Для приложений с несколькими процессами общий лимит между процессами нужно координировать отдельно.

## Настройка

```rust
use std::time::Duration;
use vkbots::VkBot;

let bot = VkBot::builder("ТОКЕН")
    .requests_per_second(3)
    .max_retries(4)
    .retry_delays(Duration::from_millis(300), Duration::from_secs(8))
    .build()?;
```

## Повторные запросы

Ошибки VK API с кодами 6 (слишком много запросов в секунду), 9 (Flood control) и 29 (ограничение частоты) повторяются с экспоненциальной задержкой до установленного количества попыток.

Остальные ошибки возвращаются сразу. Ошибки сетевого соединения автоматически не повторяются: не все методы VK безопасно повторять после неопределённого сетевого результата.

Ограничения VK зависят от метода, токена, приложения и сообщества. Не воспринимайте выбранное значение как универсальную гарантию допустимой частоты. При использовании нескольких экземпляров бота настройте единый внешний rate limiter.
