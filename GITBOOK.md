# Публикация документации Vkbots на GitBook

Документация расположена в каталоге `book/`. В корне репозитория находится `.gitbook.yaml`: он указывает GitBook, где находятся Markdown-страницы, главная страница и навигация.

## Подключение репозитория

1. Войдите в GitBook и создайте Documentation site.
2. Создайте или откройте Space для документации Vkbots.
3. Выберите **Set up Git Sync**.
4. Подключите GitHub и установите приложение GitBook для аккаунта, в котором находится репозиторий.
5. Выберите репозиторий `ZeeinJordansky/Vkbots` и ветку `main`.
6. Для первого импорта выберите направление **GitHub → GitBook**.
7. Убедитесь, что GitBook использует корень документации `./book/` из `.gitbook.yaml`.
8. Запустите синхронизацию и проверьте, что первой страницей стала `book/README.md`, а навигация взята из `book/SUMMARY.md`.
9. Создайте или откройте Docs site, добавьте в него этот Space и нажмите **Publish**.

GitBook поддерживает Git Sync с GitHub и двустороннюю синхронизацию. После подключения изменения Markdown в репозитории будут поступать в GitBook, а изменения в редакторе GitBook могут синхронизироваться обратно в GitHub. Для репозитория с исходным кодом сначала используйте GitHub → GitBook, чтобы не перезаписать файлы библиотеки импортированной структурой.

## Обновление документации

Редактируйте файлы в `book/` и отправляйте коммиты в `main`. GitBook подтянет изменения через Git Sync. Перед публикацией проверяйте ссылки, заголовки и порядок страниц в `SUMMARY.md`.
