# История изменений

## 0.2.0

- Добавлен Dispatcher с обработчиками команд и фильтрами сообщений.
- Добавлен FSM с MemoryStorage и интерфейсом пользовательского StateStorage.
- Добавлена загрузка локальных фотографий через полный цикл VK Upload API.
- Добавлены типизированные параметры и ответы для messages.send, users.get и методов загрузки фотографий.
- Добавлены общий rate limiter и повторы временных ошибок VK API.
- Настроен общий HTTP connection pool.
- Добавлены integration-тесты повторных запросов и загрузки фото.
- Добавлены примеры Dispatcher, FSM, клавиатуры, бесед и Callback API за Nginx.
- Расширена документация GitBook.

## 0.1.0

- Добавлен асинхронный клиент VK API.
- Добавлен универсальный вызов методов через `ApiClient::call`.
- Добавлены методы `send.answer` и `send.reply`.
- Добавлен builder для сообщений, вложений и клавиатур.
- Добавлена модель события и сообщения.
- Добавлено получение событий через Bots Long Poll.
- Добавлен HTTP-сервер Callback API.
- Добавлены примеры, GitBook-документация и CI.
