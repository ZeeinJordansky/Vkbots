# История изменений

## 0.1.0

- Добавлен асинхронный клиент VK API.
- Добавлен универсальный вызов методов через `ApiClient::call`.
- Добавлены методы `send.answer` и `send.reply`.
- Добавлен builder для сообщений, вложений и клавиатур.
- Добавлена модель события и сообщения.
- Добавлено получение событий через Bots Long Poll.
- Добавлен HTTP-сервер Callback API.
- Добавлены примеры, GitBook-документация и CI.
